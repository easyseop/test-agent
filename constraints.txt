# Pinned resolution for reproducible Runner installs.
#
#   python3 -m pip install -e ".[db,dev]" -c constraints.txt
#   python3 -m playwright install chromium
#
# Why this file exists: `requirements.txt` used open `>=` ranges, so two machines
# installing on different days got different Playwright builds. Playwright pins the
# browser revision it expects, so a version drift shows up as "browser not found"
# or a revision mismatch rather than an obvious dependency error.
#
# Regenerate after a deliberate upgrade:
#   python3 -m pip install -e ".[db,dev]" --upgrade && python3 -m pip freeze > constraints.txt
# then re-run `python3 -m playwright install chromium` and the demo suites.
#
# Verified on Python 3.11.15 / 3.12 with Chromium 141.
